# 🏠 Cybersecurity Learning Vault

Bienvenido al **Cybersecurity Learning Vault**, tu base de operaciones para aprender Ciberseguridad desde cero hasta un nivel profesional.

Este Vault de Obsidian está diseñado para ser tu curso, laboratorio, y base de conocimiento central.

---

## 🎯 Objetivo

El objetivo es proporcionarte un camino estructurado y progresivo. No vas a saltar directamente a "hackear" sin entender cómo funciona una red, ni vas a defender un sistema sin saber cómo funciona por dentro.

El enfoque es: **Fundamentos primero, especialización después.**

---

## 👥 ¿Para quién es esto?

- **Principiantes absolutos** que no saben por dónde empezar. (Empiecen por el [[01 - Introducción a la Ciberseguridad|Módulo 01]]).
- **Estudiantes de IT** que quieren transicionar a seguridad.
- **Profesionales junior** buscando estructurar sus conocimientos para certificaciones.
- **Entusiastas** que quieren una base de conocimiento interconectada.

**Conocimientos previos:** Se asume que sabes usar una computadora a nivel usuario, navegar por internet y tenés nociones muy básicas de informática. Todo lo demás (redes, Linux, Windows) se enseña desde cero.

---

## 🗺️ Cómo Utilizar el Vault

1. **Revisá el Roadmap:** Entrá a [[Roadmap]] para entender el camino general.
2. **Seguí el orden:** Empezá por `01 - Fundamentos` y no saltes módulos a menos que ya domines el tema.
3. **Usa el Progreso:** Marcá tus avances en [[Progreso]].
4. **Hacé los Laboratorios:** La teoría no sirve sin práctica. Los laboratorios están para ensuciarse las manos.
5. **Autoevaluate:** Usá las evaluaciones al final de cada módulo.

---

## 🧠 Cómo Estudiar (El Método)

1. **Lee la teoría** de una nota.
2. **Entendé los enlaces:** Si una nota enlaza a otra, hacé clic y lee la referencia si no conocés el concepto.
3. **Identificá las secciones:**
   - `#must-know`: Tenés que saberlo de memoria.
   - `#good-to-know`: Importante, pero podés consultarlo cuando lo necesites.
   - `#advanced`: Si estás empezando, podés saltarlo por ahora.
4. **Práctica Activa:** Hacé los ejercicios de repaso al final de cada nota.
5. **No copies y pegues:** Escribí tus propios resúmenes si es necesario.

## 💻 Laboratorios

Los laboratorios son esenciales. Encontrarás:

- **Laboratorios de Módulo:** Prácticas cortas integradas en cada módulo (ej. `03 - Linux/21 - Laboratorio.md`).
- **Laboratorios Centralizados:** Escenarios más complejos en la carpeta `27 - Laboratorios/`.
- **Proyectos:** Desafíos grandes para tu portfolio en `28 - Proyectos/`.

Para empezar, leé la [[00 - Guía de Laboratorios]].

---

## 📝 Evaluaciones

Cada módulo termina con una evaluación para poner a prueba lo que aprendiste.

- Las evaluaciones están centralizadas en `29 - Evaluaciones/`.
- Hacé las evaluaciones **sin mirar los apuntes** primero.
- Las respuestas están en `29 - Evaluaciones/Respuestas/`. ¡No hagas trampa!

## 🔗 Utilizando Obsidian

Este Vault está pensado para sacar el jugo a Obsidian:

- **Enlaces `[[ ]]`:** Hacé clic para navegar entre conceptos relacionados.
- **Graph View (Ctrl+G):** Usá la vista de grafo para ver cómo se conectan los conceptos. Es excelente para entender la "big picture".
- **Backlinks:** Al final de una nota, mirá qué otras notas la mencionan.
- **Búsqueda (Ctrl+Shift+F):** Buscá cualquier término en todo el Vault.
