# 📖 Glosario de Ciberseguridad

Este glosario contiene las definiciones breves de los términos más importantes utilizados a lo largo del Vault. 

Hacé clic en los enlaces para ir a las notas detalladas donde se explican los conceptos en profundidad.

*(Nota: Este glosario se encuentra en construcción y crecerá a medida que avances en el roadmap).*

---

## A

- **[[08 - Identity & Access/02 - Authentication Mechanisms|Authentication (Autenticación)]]:** Proceso de verificar la identidad de un usuario, dispositivo o sistema. (El "quién sos").
- **[[08 - Identity & Access/05 - Access Control Models|Authorization (Autorización)]]:** Proceso de determinar a qué recursos tiene acceso un usuario autenticado y qué acciones puede realizar. (El "qué podés hacer").

## C

- **[[11 - Vulnerability Management/01 - CVE|CVE (Common Vulnerabilities and Exposures)]]:** Lista pública y estandarizada de vulnerabilidades de seguridad conocidas en software y hardware.
- **[[11 - Vulnerability Management/02 - CVSS|CVSS (Common Vulnerability Scoring System)]]:** Framework abierto para comunicar las características y la severidad de las vulnerabilidades.
- **[[11 - Vulnerability Management/03 - CWE|CWE (Common Weakness Enumeration)]]:** Lista comunitaria de debilidades de software y hardware que pueden llevar a vulnerabilidades.

## E

- **[[13 - Defensive Security/07 - EDR|EDR (Endpoint Detection and Response)]]:** Herramientas de seguridad que monitorean endpoints de forma continua para detectar y responder a amenazas avanzadas, yendo más allá de los antivirus tradicionales.
- **[[06 - Cryptography/01 - Conceptos Básicos|Encryption (Cifrado)]]:** Proceso de convertir texto plano en un formato ilegible (texto cifrado) utilizando un algoritmo y una clave.
- **[[12 - Offensive Security/11 - Exploitation Concepts|Exploit]]:** Código, script o técnica que aprovecha una vulnerabilidad específica para comprometer un sistema.

## F

- **[[07 - Network Security/02 - Firewalls|Firewall]]:** Dispositivo o software de seguridad de red que monitorea y controla el tráfico entrante y saliente basándose en reglas de seguridad predeterminadas.

## H

- **[[06 - Cryptography/07 - Hashing|Hashing]]:** Proceso matemático que convierte datos de cualquier tamaño en una cadena de longitud fija (hash). Es unidireccional y se usa para verificar integridad.

## I

- **[[14 - SOC & SIEM/13 - IOC|IOC (Indicator of Compromise)]]:** Pieza de evidencia forense (ej. una IP maliciosa, un hash de malware) que indica con alta confianza que la red o el sistema ha sido comprometido.
- **[[14 - SOC & SIEM/14 - IOA|IOA (Indicator of Attack)]]:** Evidencia física o digital de que un ataque cibernético está en progreso (el comportamiento del atacante), independiente de si usó herramientas conocidas o no.
- **[[13 - Defensive Security/06 - IDS e IPS|IDS (Intrusion Detection System)]]:** Sistema que monitorea el tráfico de red en busca de actividad maliciosa y genera alertas (detecta pero no bloquea).
- **[[13 - Defensive Security/06 - IDS e IPS|IPS (Intrusion Prevention System)]]:** Sistema que monitorea el tráfico de red y toma acciones automáticas para bloquear amenazas detectadas.

## S

- **[[14 - SOC & SIEM/03 - SIEM en Profundidad|SIEM (Security Information and Event Management)]]:** Solución de seguridad que recolecta, analiza y correlaciona logs y eventos de múltiples fuentes en tiempo real para detectar amenazas.
- **[[14 - SOC & SIEM/01 - Qué es un SOC|SOC (Security Operations Center)]]:** Equipo centralizado (y la instalación física/virtual) responsable de monitorear y mejorar continuamente la postura de seguridad de una organización, previniendo, detectando y respondiendo a incidentes.

## T

- **[[05 - Security Fundamentals/11 - Threat Actors|Threat Actor]]:** Persona, grupo u organización que tiene la intención y la capacidad de realizar ciberataques.
- **[[14 - SOC & SIEM/15 - TTP|TTP (Tactics, Techniques, and Procedures)]]:** El comportamiento operativo de los ciberatacantes. Tácticas (el objetivo), Técnicas (cómo lo logran) y Procedimientos (la ejecución paso a paso).

## V

- **[[05 - Security Fundamentals/09 - Threat Vulnerability Exploit Risk|Vulnerability (Vulnerabilidad)]]:** Debilidad en un sistema, aplicación o red que puede ser explotada por una amenaza para comprometer la seguridad.

## X

- **[[13 - Defensive Security/08 - XDR|XDR (Extended Detection and Response)]]:** Evolución del EDR que integra datos de seguridad de múltiples fuentes (endpoints, red, nube, correo) para ofrecer detección y respuesta más holísticas.
