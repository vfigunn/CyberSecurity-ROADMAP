# 📖 Glosario de Ciberseguridad

Este glosario contiene las definiciones breves de los términos más importantes utilizados a lo largo del Vault. 

Hacé clic en los enlaces para ir a las notas detalladas donde se explican los conceptos en profundidad.

*(Nota: Este glosario se encuentra en construcción y crecerá a medida que avances en el roadmap).*

---

## A

- **[[06 - Windows/08 - Autenticación I (NTLM y el problema del Hash)|Authentication (Autenticación)]]:** Proceso de verificar la identidad de un usuario, dispositivo o sistema. (El "quién sos").
- **[[06 - Windows/11 - Políticas de Grupo (GPOs - El arma de doble filo)|Authorization (Autorización)]]:** Proceso de determinar a qué recursos tiene acceso un usuario autenticado y qué acciones puede realizar. (El "qué podés hacer").

## C

- **[[01 - Fundamentos/05 - Vulnerabilidades|CVE (Common Vulnerabilities and Exposures)]]:** Lista pública y estandarizada de vulnerabilidades de seguridad conocidas en software y hardware.
- **[[01 - Fundamentos/05 - Vulnerabilidades|CVSS (Common Vulnerability Scoring System)]]:** Framework abierto para comunicar las características y la severidad de las vulnerabilidades.
- **[[01 - Fundamentos/05 - Vulnerabilidades|CWE (Common Weakness Enumeration)]]:** Lista comunitaria de debilidades de software y hardware que pueden llevar a vulnerabilidades.

## E

- **[[07 - Web Hacking/00 - Overview|EDR (Endpoint Detection and Response)]]:** Herramientas de seguridad que monitorean endpoints de forma continua para detectar y responder a amenazas avanzadas, yendo más allá de los antivirus tradicionales.
- **[[05 - Criptografía/06 - Criptografía Simétrica (AES, DES)|Encryption (Cifrado)]]:** Proceso de convertir texto plano en un formato ilegible (texto cifrado) utilizando un algoritmo y una clave.
- **[[08 - Metasploit/01 - Arquitectura y Terminología (Exploit, Payload, Auxiliary)|Exploit]]:** Código, script o técnica que aprovecha una vulnerabilidad específica para comprometer un sistema.

## F

- **[[02 - Networking/25 - Dispositivos de Seguridad en Red|Firewall]]:** Dispositivo o software de seguridad de red que monitorea y controla el tráfico entrante y saliente basándose en reglas de seguridad predeterminadas.

## H

- **[[05 - Criptografía/04 - Hashing I (Conceptos, MD5, SHA-256)|Hashing]]:** Proceso matemático que convierte datos de cualquier tamaño en una cadena de longitud fija (hash). Es unidireccional y se usa para verificar integridad.

## I

- **[[09 - Red Team y OSINT/07 - Armado de Reportes y Triage|IOC (Indicator of Compromise)]]:** Pieza de evidencia forense (ej. una IP maliciosa, un hash de malware) que indica con alta confianza que la red o el sistema ha sido comprometido.
- **[[09 - Red Team y OSINT/07 - Armado de Reportes y Triage|IOA (Indicator of Attack)]]:** Evidencia física o digital de que un ataque cibernético está en progreso (el comportamiento del atacante), independiente de si usó herramientas conocidas o no.
- **[[02 - Networking/25 - Dispositivos de Seguridad en Red|IDS (Intrusion Detection System)]]:** Sistema que monitorea el tráfico de red en busca de actividad maliciosa y genera alertas (detecta pero no bloquea).
- **[[02 - Networking/25 - Dispositivos de Seguridad en Red|IPS (Intrusion Prevention System)]]:** Sistema que monitorea el tráfico de red y toma acciones automáticas para bloquear amenazas detectadas.

## S

- **[[09 - Red Team y OSINT/06 - Command and Control (C2 Frameworks)|SIEM (Security Information and Event Management)]]:** Solución de seguridad que recolecta, analiza y correlaciona logs y eventos de múltiples fuentes en tiempo real para detectar amenazas.
- **[[09 - Red Team y OSINT/06 - Command and Control (C2 Frameworks)|SOC (Security Operations Center)]]:** Equipo centralizado (y la instalación física/virtual) responsable de monitorear y mejorar continuamente la postura de seguridad de una organización, previniendo, detectando y respondiendo a incidentes.

## T

- **[[01 - Fundamentos/11 - Threat Actors|Threat Actor]]:** Persona, grupo u organización que tiene la intención y la capacidad de realizar ciberataques.
- **[[09 - Red Team y OSINT/05 - Cyber Kill Chain y MITRE ATT&CK|TTP (Tactics, Techniques, and Procedures)]]:** El comportamiento operativo de los ciberatacantes. Tácticas (el objetivo), Técnicas (cómo lo logran) y Procedimientos (la ejecución paso a paso).

## V

- **[[01 - Fundamentos/05 - Vulnerabilidades|Vulnerability (Vulnerabilidad)]]:** Debilidad en un sistema, aplicación o red que puede ser explotada por una amenaza para comprometer la seguridad.

## X

- **[[07 - Web Hacking/00 - Overview|XDR (Extended Detection and Response)]]:** Evolución del EDR que integra datos de seguridad de múltiples fuentes (endpoints, red, nube, correo) para ofrecer detección y respuesta más holísticas.
