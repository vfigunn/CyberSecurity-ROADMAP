# 03 - Linux

Bienvenido al Módulo 03. Si Networking es la autopista por donde viajan los atacantes, **Linux es la casa a la que intentan entrar (y desde donde lanzan sus ataques).**

El 90% del trabajo en ciberseguridad se realiza frente a una pantalla negra con letras blancas: la Terminal de Linux. Tanto el atacante (Red Team) utilizando distribuciones como Kali o Parrot OS, como el defensor (Blue Team) revisando logs de servidores, utilizan Linux intensivamente. 

Aprender a moverse en Linux sin depender del mouse es una de las habilidades más empoderadoras que vas a adquirir en esta carrera.

## 🎯 ¿Qué vas a lograr?

Al finalizar este módulo, vas a ser capaz de:
- Navegar con fluidez por todo el sistema operativo utilizando únicamente comandos.
- Buscar rápidamente una palabra clave (como un error o una IP atacante) dentro de miles de archivos de texto.
- Entender exactamente por qué un archivo no se puede ejecutar y cómo modificar sus permisos (`chmod`).
- Detener programas congelados o maliciosos (`kill`).
- Automatizar tareas repetitivas creando tus primeros scripts en Bash.
