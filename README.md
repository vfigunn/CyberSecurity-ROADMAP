# 🛡️ Cybersecurity Learning Vault (Bóveda Zettelkasten)

**Un currículum completo de Ciberseguridad Ofensiva en español** — desde cero hasta nivel profesional.

Este repositorio es un **Vault de Obsidian** diseñado como curso autodidacta, base de conocimiento y roadmap para transformar a un principiante en un Analista técnico corporativo.

---

## 🎯 ¿Qué es este proyecto?

Este repositorio funciona como:
- 📚 **Curso autodidacta** de Ciberseguridad Ofensiva y Defensiva.
- 🗺️ **Roadmap progresivo** desde fundamentos hasta especialización.
- 🧠 **Base de conocimiento (Zettelkasten)** interconectada.
- 🔬 **Sistema de laboratorios** teóricos integradores.
- 📝 **Evaluaciones** por módulo con formato Multiple Choice.
- 🧰 **Arsenal Hacker** con el Top 50 de herramientas.
- 🏆 **Mapa de certificaciones** y guía de carrera (OSCP, PNPT, eJPT).

## 🚀 Cómo Usar (Instalación)

Este proyecto fue diseñado estrictamente para ser leído a través de la herramienta gratuita **Obsidian**, la cual te permitirá navegar los enlaces y visualizar el mapa mental (Grafo).

1. **Clonar** el repositorio:
   ```bash
   git clone https://github.com/vfigunn/CyberSecurity-ROADMAP.git
   ```

2. **Abrir en Obsidian:**
   - Descargar e instalar [Obsidian](https://obsidian.md/).
   - Abrir como Vault: Seleccioná `Open folder as vault`.
   - Elegí la carpeta descargada `CyberSecurity-ROADMAP/`.

3. **Comenzar a aprender:**
   - Abrí la carpeta `00 - Inicio/` y lee la nota `README.md`.
