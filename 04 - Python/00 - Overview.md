# 04 - Python

Bienvenido al Módulo 04. Si Linux es tu sistema de transporte, **Python es tu fábrica de armas y herramientas.**

Mientras que un administrador de sistemas normal utiliza herramientas creadas por otros, un profesional de la Ciberseguridad necesita la capacidad de construir sus propias herramientas a medida cuando los programas comerciales fallan o no se adaptan al entorno.
Python es el lenguaje dominante en el hacking (creación de exploits, automatización de escaneos) y en la defensa (orquestación SOAR, análisis de malware, parseo de logs).

No necesitas ser un Desarrollador de Software Senior para ser útil en ciberseguridad, pero sí necesitas ser un excelente "Scripter" (alguien que ensambla código para solucionar un problema rápido).

## 🎯 ¿Qué vas a lograr?

Al finalizar este módulo, vas a ser capaz de:
- Escribir scripts modulares y limpios en Python.
- Procesar inmensos archivos de logs (JSON o CSV) y extraer información específica mediante diccionarios.
- Manejar errores de red para que tus scripts no se bloqueen al escanear (Excepciones).
- Utilizar librerías externas para hacer peticiones web o crear conexiones de red directas a bajo nivel.
- Comprender el código fuente de herramientas de Hacking escritas por otros para poder modificarlas.
